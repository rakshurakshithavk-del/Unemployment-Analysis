# Unemployment Analysis with Python

## CodeAlpha Internship - Task 2

This project analyzes unemployment data in India using Python, data analysis, and visualization techniques.

## Objectives

- Analyze unemployment rate data
- Clean and explore the dataset
- Study unemployment trends over time
- Compare unemployment rates across different regions
- Analyze the impact of COVID-19 on unemployment
- Study labour participation and employment
- Identify important patterns in the data

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The project uses the **Unemployment in India** dataset provided for the CodeAlpha internship.

## Analysis Performed

1. Data loading
2. Data cleaning
3. Missing-value analysis
4. Statistical analysis
5. Unemployment trend visualization
6. Region-wise unemployment analysis
7. Area-wise unemployment analysis
8. COVID-19 impact analysis
9. Employment analysis
10. Labour participation analysis
11. Correlation analysis
12. Data visualization

## Files

- `Unemployment_Analysis.ipynb` - Complete Python analysis
- `Unemployment in India.csv` - Dataset

## Conclusion

The analysis helps understand unemployment trends in India and examines changes in unemployment during the COVID-19 period. Visualizations and statistical analysis are used to identify patterns in unemployment, employment, and labour participation.
